# Simple Task Manager (To-Do List)

A command-line to-do list application written in Python, created for the Applied Programming Project course.

## What it does
- Add tasks with a title, deadline, and priority (low, medium, high)
- View all tasks
- Mark tasks as done
- Edit and delete tasks
- Filter tasks by status (pending or done) and by priority
- Save tasks automatically to a file, so nothing is lost when the program closes
- Check user input, so wrong entries do not crash the program

## Requirements
- Python 3 (no extra libraries needed)

## How to run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:
   ```
   python TODO.py
   ```
4. Choose an option from the menu by typing its number.

## How to use
| Option | What it does |
|--------|--------------|
| 1 | Add a new task (title, deadline in YYYY-MM-DD format, priority) |
| 2 | Show all tasks |
| 3 | Mark a task as done |
| 4 | Delete a task |
| 5 | Edit a task title |
| 6 | Filter tasks by status or priority |
| 7 | Quit |

## Data storage
Tasks are saved in a file called `tasks.json`, which the program creates automatically the first time you add a task.

## Project structure
- `TODO.py`: the main program
- `tasks.json`: saved tasks (created automatically)
- `README.md`: this file
